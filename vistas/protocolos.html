Procedimientos Operativos de Emergencia

  1. Protocolo de Contención para Ransomware
    • Paso 1: Aislar inmediatamente el equipo o servidor afectado de la red corporativa (desconectar cable de red o Wi-Fi).
    • Paso 2: Notificar al equipo SOC/CSIRT y registrar la hora exacta del ataque.
    • Paso 3: Identificar la variante del ransomware analizando las extensiones de los archivos cifrados.
    • Paso 4: Proceder con la restauración de los datos limpios utilizando las últimas copias de seguridad (Backup).

  2. Protocolo de Mitigación para Denegación de Servicio (DoS)
    • Paso 1: Monitorear el tráfico de red mediante herramientas de análisis enrutado para identificar la IP de origen del ataque.
    • Paso 2: Aplicar reglas de filtrado o listas de control de acceso (ACLs) en los routers/firewalls perimetrales para bloquear el tráfico malicioso.
    • Paso 3: Activar el servicio de mitigación contra DDoS con el proveedor de internet (ISP) si el volumen satura el ancho de banda.

  3. Protocolo de Respuesta ante Filtración de Datos
    • Paso 1: Revocar de inmediato las credenciales de acceso y tokens activos de las cuentas comprometidas.
    • Paso 2: Analizar los registros (logs) del sistema para determinar qué información exacta fue sustraída.
    • Paso 3: Informar al oficial de seguridad y cumplir con el reporte de notificación a los involucrados según normativas corporativas.
